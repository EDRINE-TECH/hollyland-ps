# Hollyland Nursery and Primary School Website

A demonstration website for Hollyland Nursery and Primary School in Kawanda, Kampala, Uganda.

## Project plan

- HTML, CSS and vanilla JavaScript
- Responsive desktop, tablet and mobile layouts
- Pages: Home, About Us, Academics, Admissions, Our Staff, Our Gallery, News & Events, and Contact Us
- No admin dashboard or database in this demonstration version

School contact details, staff information, and photographs must be verified with the school before publication.
